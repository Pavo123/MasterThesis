# MasterThesis
A MULTI-OBJECTIVE DEMAND ALLOCATION METHOD FOR EMERGENCY SHELTERS BASED ON DEEP REINFORCEMENT LEARNING

The file DRL_Env.ipynb contains the full code that was made to develop the environment, run hyperparameter optimisation, train the model, test the model and produce the visualization results as well as the evaluation metrics.
The iam_ppo_model_tuned_Final_Run_04092026.zip is the trained model.
The tuning_results_12082026_final.json is the used hyperparameters set.
